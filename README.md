# CHIP Vascular

## Overview

This repository contains the computational analysis code supporting the manuscript:

**Monocyte-endothelial interactions as a targetable node in clonal hematopoiesis-mediated cardiovascular disease**

[Read the manuscript on eLife](https://elifesciences.org/reviewed-preprints/109131)

This study investigates how CHIP-associated mutations in **TET2** and **DNMT3A** influence monocyte-endothelial interactions and contribute to cardiovascular disease.

The analyses use single-cell RNA sequencing data to characterize cell populations, identify mutation-associated changes in gene expression, and investigate cell-cell communication.

## Repository Contents

The repository includes scripts for:

- Single-cell RNA sequencing processing and quality control.
- Sample demultiplexing and doublet removal.
- Seurat normalization and dataset integration.
- Cell-type annotation.
- Cell-cell communication analysis using CellChat.
- Metacell generation.
- Differential gene expression analysis.
- Downstream analysis of monocyte-endothelial interactions.

Scripts are numbered to reflect the general order of the analysis workflow.

## Data Availability

Single-cell RNA sequencing data associated with this study will be made publicly available through [CELLxGENE Discover](https://cellxgene.cziscience.com/).

Raw sequencing data and intermediate analysis files may require separate access.

## Running the Analyses

To run the analyses:

1. Clone this repository:

   ```bash
   git clone https://github.com/bicklab/CHIP_vascular.git
   ```

2. Install the required R and Python packages.
3. Download the relevant datasets from CELLxGENE when available.
4. Update file paths in the analysis scripts as needed.
5. Run the scripts in the numbered order.

Some analyses require intermediate files generated by preceding scripts.
